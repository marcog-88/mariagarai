# EXPONENCIAL COPY BRIEF TEMPLATE v1
**Exponencial — Landing Page Copy System**
Last updated: June 2026
Use this to write copy for any new program page before opening Claude Code or Cursor.
One doc per program. Fill every section. Hand to Claude to write the final copy.

---

## HOW TO USE THIS

1. Fill in the PROGRAM INFO block at the top
2. Answer the prompts in each section — bullets, notes, rough ideas are fine
3. Hand the completed brief to Claude
4. Claude writes the final page copy
5. Paste final copy into the Claude Code / Cursor build brief

**Rule:** María fills the brief. Claude writes the copy. Marco builds the page.
